# 案例库远端主存 P0 字段字典

- 日期：2026-11-20
- 契约：案例数据网关 OpenAPI 1.8.0
- OpenAPI SHA-256：`f216a1e58a44a049a3f53fccceb9c751cf1b3c56a1dcc58ce1ee07672d63816b`
- 数据主存：`libiaolink_case` 与案例版本化对象桶
- 合并目录：`project_read.project_directory`；`project_summary` 只保存核心只读投影

## 1. 权威与版本规则

| 对象 | 写入表 | 读取视图 | 并发字段 | 递增规则 |
|---|---|---|---|---|
| 核心项目 | 核心 `public.projects/users`，仅只读 | `project_read.project_summary` | `sourceVersion` | 核心 `projects.version` |
| 本地项目 | `project_read.local_projects` | `project_directory` | `sourceVersion` | 创建为 1；每次真实 PATCH 加 1 |
| 项目 profile | `case.project_profiles` | 项目 profile 接口 | `rowVersion` | 首次保存期望 0，返回 1；真实变更加 1 |
| 案例 | `case.cases` | 案例详情/列表 | `rowVersion` | 首次创建为 1；真实 PATCH/恢复加 1 |
| 案例版本 | `case.case_versions` | 案例版本接口 | `versionNo` | 首次创建版本 1；每次真实变更追加下一版本 |
| 素材元数据 | `case.case_asset_metadata` | 素材详情/列表 | `rowVersion` | 首次登记为 1；真实 PATCH 加 1 |
| 素材版本 | `case.case_assets` | 素材版本接口 | `versionNo` | 同一 `assetId` 每次重新上传加 1 |

项目目录项没有独立 `rowVersion`；项目 PATCH 的 `expectedVersion` 使用 `sourceVersion`。项目 profile 的 `expectedVersion` 使用 profile `rowVersion`，同时提交当前目录项 `sourceVersion` 作为来源一致性校验。无实际变化的 PATCH 成功但不递增版本、不新增案例历史版本。

## 2. 项目目录字段

| 字段 | 类型/范围 | 必填 | 可空 | 写入权威 | 版本影响 |
|---|---|---:|---:|---|---|
| `externalProjectId` | UUID | 是 | 否 | 核心投影或本地项目；创建后不可变 | 不单独递增 |
| `projectCode` | string 1–50 | 是 | 否 | 核心项目只读；本地项目 PATCH | 本地真实变更 +1 |
| `projectName` | string 1–200 | 是 | 否 | 核心项目只读；本地项目 PATCH | 本地真实变更 +1 |
| `customerText` | string ≤200 | 否 | 是 | 核心文本只读；本地项目 PATCH | 本地真实变更 +1 |
| `region` | string 1–100，默认“未分类” | 否 | 否 | 核心只读；本地项目 PATCH | 本地真实变更 +1 |
| `projectType` | string 1–100，默认“未分类” | 否 | 否 | 核心只读；本地项目 PATCH | 本地真实变更 +1 |
| `managerIds` | UUID 数组，≤200 | 否 | 否 | 核心只读；本地项目 PATCH | 本地真实变更 +1 |
| `managerNames` | (string/null) 数组，≤200 | 否 | 项可空 | 核心按 `users.display_name` 投影；本地项目请求给出 | 与 managerIds 同序同长 |
| `status` | `active/paused/done/archived` | 是 | 否 | 核心只读；本地项目 PATCH | 归档/解档、状态变更 +1 |
| `sourceKind` | `core/local` | 是 | 否 | 只读派生 | 否 |
| `sourceVersion` | integer ≥0 | 是 | 否 | 核心 `projects.version`；本地从 1 起 | 本地真实变更 +1 |
| `updatedAt` | timestamp | 是 | 否 | 核心 `updated_at`；本地 PATCH 时间 | 随真实变更 |
| `archivedAt` | timestamp | 是 | 是 | `status=archived` 时设置；改回其它状态清空 | 随状态变更 |
| `deletedAt` | timestamp | 是 | 是 | 本地 PATCH `deleted` | 软删除/恢复 +1 |
| `syncedAt` | timestamp | 是 | 否 | 投影或本地写事务时间 | 否 |

唯一性：`externalProjectId` 在所有核心历史摘要与本地项目间永久唯一；`projectCode` 在未软删除、未标记源缺失的目录可用项间跨来源唯一。归档仍占用编号，软删除释放编号。冲突码为 `PROJECT_ID_EXISTS` / `PROJECT_CODE_EXISTS`。

## 3. 项目 profile 与主体字段

profile 写入 `case.project_profiles`，主体别名等写 `case.subjects`、`case.subject_aliases`、`case.project_subjects`、`case.project_members`。

| 字段 | 类型/范围 | 必填 | 可空 | 说明 |
|---|---|---:|---:|---|
| `sourceVersion` | integer ≥0 | 是 | 否 | 必须等于当前项目目录 `sourceVersion` |
| `expectedVersion` | integer ≥0 | 是 | 否 | profile `rowVersion`；首次为 0 |
| `attributes.deliveryYear` | integer 2000–2100 | 否 | 是 | 交付年份 |
| `attributes.customerSubjectId` | UUID | 否 | 是 | 客户稳定主体 ID |
| `attributes.customerDisplayName` | string 1–256 | 否 | 是 | 客户显示名 |
| `attributes.customerAliases` | string[] ≤100 | 否 | 是 | 客户别名 |
| `attributes.customerLogoAssetId` | UUID | 否 | 是 | 项目素材库中的 Logo 素材 ID |
| `attributes.partnerType` | string ≤64 | 否 | 是 | 合作方类型 |
| `attributes.partnerKey` | string ≤128 | 否 | 是 | 合作方稳定键 |
| `attributes.partnerDisplayName` | string ≤256 | 否 | 是 | 合作方显示名 |
| `attributes.threePlKey` | string ≤128 | 否 | 是 | 3PL 稳定键 |
| `attributes.threePlDisplayName` | string ≤256 | 否 | 是 | 3PL 显示名 |
| `attributes.relationshipType` | string ≤64 | 否 | 是 | 客户/合作方关系 |
| `attributes.regions` | string[] ≤50 | 否 | 是 | 地区多值 |
| `attributes.regionCodes` | string[] ≤50 | 否 | 是 | 地区编码 |
| `attributes.country` | string ≤100 | 否 | 是 | 国家文本 |
| `attributes.countryCode` | `^[A-Z]{2}$` | 否 | 是 | ISO 国家码 |
| `attributes.industry` | string ≤100 | 否 | 是 | 行业文本 |
| `attributes.industryCode` | string ≤64 | 否 | 是 | 行业编码 |
| `attributes.scenarioCode` | string ≤64 | 否 | 是 | 场景编码 |
| `attributes.businessScenario` | string ≤200 | 否 | 是 | 业务场景 |
| `attributes.solutionTypes` | enum[] ≤7 | 否 | 是 | `airrob/airrob_pro/airrob_plus/t_sort/t_carry/3d/grabot` |
| `attributes.canVisit` | boolean | 否 | 是 | 是否可参观 |
| `subjects[]` | `{subjectId,subjectType,isPrimary}` | 是 | 否 | 主体关系完整清单；类型为客户/合作方/3PL |
| `members[]` | `{operatorUserKey,roleCode,source,isPrimary,leftAt}` | 是 | 否 | 成员完整清单；`leftAt` 为 UTC 时间 |

## 4. 案例字段与历史版本

| 字段 | 类型/范围 | 规则 |
|---|---|---|
| `caseId` | UUID | 调用方可预生成，创建后不可变 |
| `sourceProjectId` | UUID | 项目目录中的 `externalProjectId`，不可变 |
| `translationGroupId` | UUID | 同组语言共享；省略时使用 `caseId` |
| `locale` | BCP-47 风格，2–20 | 一语言一案例；创建后不可变 |
| `title` | string 1–300 | 必填 |
| `summary` | string ≤5000 | 可空 |
| `changeSummary` | string 1–1000 | 可空；恢复版本可选 |
| `reviewStatus` | `not_submitted/reviewing/approved/rejected` | 调用方审核镜像；网关不判定业务审核 |
| `reviewRef` | string ≤256 | 可空的不透明审核引用 |
| `status` | `draft/reviewing/published/archived/deleted` | 派生：删除 > 归档 > active release > 审核中 > 草稿 |
| `activeReleaseId` | UUID | 当前 active release，可空 |
| `rowVersion` | integer ≥1 | 真实变更递增 |
| `archivedAt` | timestamp | 可空 |
| `deletedAt` | timestamp | 可空；软删除后列表可过滤 |
| `content` | v1 对象 | `schemaVersion=1`；文本/亮点 key 白名单；每字段密级和分享属性 |
| `solutionParameters` | v1 对象 | `schemaVersion=1`；方案类型和参数名白名单 |
| `outcomes` | v1 对象 | `schemaVersion=1`；指标 label/value/unit |
| `confidentiality` | v1 对象 | 新建必填；含 mode/customerIdentity/contentVisibility/mediaPermission/internalScope |
| `createdBy` | string | 取创建请求 `operatorUserKey` |
| `createdAt/updatedAt` | timestamp | 服务端生成 |

`case_versions` 保存每个真实变更的完整快照：locale、translationGroupId、title、summary、changeSummary、content、solutionParameters、outcomes、confidentiality。首版版本号为 1；恢复历史版本会生成新的当前版本，不覆盖旧历史。

## 5. 素材元数据与素材版本

| 字段 | 类型/范围 | 规则 |
|---|---|---|
| `assetId` | UUID | 项目内稳定资产 ID；调用方可指定或由网关生成 |
| `projectId` | UUID | 素材库所属项目 |
| `caseIds` | UUID[] | 同项目内挂接案例；可多案例 |
| `assetType` | `logo/cover/image/video/document/other` | 业务分类 |
| `title` | string ≤300 | 可空 |
| `description` | string ≤2000 | 可空 |
| `locale` | locale | 可空 |
| `tags` | string[] ≤30 | 唯一标签 |
| `classification` | `L1/L2/L3` | 密级 |
| `customerVisible` | boolean | 客户可见 |
| `customerPresentationAllowed` | boolean | 客户讲解允许 |
| `shareAllowed` | boolean | 分享允许 |
| `assetVersionId` | UUID | 不可变素材版本 ID |
| `versionNo` | integer ≥1 | 同一 asset 内递增 |
| `objectVersionId` | string | 对象存储精确版本；不向作者暴露永久对象地址 |
| `fileName` | string 1–255 | 原始文件名 |
| `mimeType` | png/jpeg/webp/avif/mp4/pdf | 按扩展名与文件头双校验 |
| `sizeBytes` | 1–268435456 | 单个素材总上限 256 MiB |
| `sha256` | 64 位小写十六进制 | 上传与恢复均校验 |
| `scanStatus` | `pending/passed/failed` | 媒体服务责任 |
| `transcodeStatus` | `not_required/pending/ready/failed` | 媒体服务责任 |
| `previewStatus` | `pending/ready/failed` | 媒体服务责任 |
| `dimensions` | `{width,height}` | 图片/视频可为空 |
| `durationMs` | integer | 视频可为空 |
| `mediaVersion` | integer ≥1 | 媒体结果并发版本 |
| `thumbnailAvailable` | boolean | 图片或 PDF 预览能力 |
| `rowVersion` | integer ≥1 | 元数据并发版本 |
| `archivedAt/deletedAt` | timestamp | 可空 |

对象键格式固定为 `projects/{projectId}/assets/{assetId}/{assetVersionId}`。历史 `cases/*` 对象只读；新版本不得复用旧对象键。被 release 引用的版本删除返回 409 `ASSET_REFERENCED`。

## 6. 不在远端主存中的控制面数据

案例小组本地仍保存用户、角色、权限、审核结论与时间线、分享授权、客户访问日志、业务审计、外部 ID 映射和 outbox 元数据。`case_releases.approval_ref` 只保存不透明引用，网关不得解释审核状态。

没有批量单接口；存量迁移按单资源稳定 ID 和 `operationId` 分批执行，并在每批后按资源 ID 与操作回执对账。
