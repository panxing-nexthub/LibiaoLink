# 案例库远端主存 P0 限制说明

- 日期：2026-11-20
- 适用版本：案例数据网关 OpenAPI 1.8.0、迁移 0014
- 环境：测试机 `10.1.104.44`
- 边界：本说明只覆盖 LibiaoLink 提供的隔离数据面，不覆盖案例小组的审核、发布、分享和本地工作流

## 1. 主存与一致性

- 远端 `libiaolink_case` 和案例对象桶是项目补充资料、案例正文和素材的唯一主存；LibiaoLink 核心库不保存这些数据。
- `project_summary` 只保存核心项目只读投影，不接收本地项目，也不得作为本地项目查询依据。
- `project_directory` 是唯一合并目录读取路径；任何页面或作业不得只查 `project_summary`。
- 本地项目写事务提交后立即可读，不等待投影；核心项目由常驻 `watch` 秒级同步，不能以 5 分钟批任务替代。
- 网关不判断案例审核、发布或撤回业务，只执行受控数据读写和版本保护。

## 2. 尚未闭环的能力

1. **C10 本地 outbox 联调**：需要案例小组提供 `case_partner_fixture` 和 v0.2 本地 schema；当前离线集成测试因此跳过 1 项。
2. **实际媒体处理作业**：网关提供 `media-input`、`media-state` 和处理身份；实际扫描、转码、缩略图 worker 由案例小组侧接入后才能验收失败重试与容量。
3. **公开缓存 / CDN**：当前为受控公开 release 读取接口；缓存命中、撤回失效、Range 和 404/410 的生产口径尚未与边缘缓存联调。
4. **批量迁移单接口**：不提供“一次提交全部存量”的批量接口；必须按项目 → 案例与语言版本 → 素材 → 挂接 → release 分批，使用稳定 ID 和 operationId。
5. **生产发布**：本轮只部署测试机；正式机需要另立发布窗口、独立备份、独立令牌轮换和发布审批。

## 3. 明确不支持或不等价的能力

- 不支持在核心项目中写入本地扩展字段；核心项目只能读取。
- 不支持删除或覆盖已发布 release 的历史快照；需要失效外链时执行 release 停用，归档不等于撤回。
- 不支持通过一个令牌同时承担作者、媒体处理和公开读取；三类身份必须分离。
- 不保证远端不可用时本地自动“继续成功”；没有本地业务兜底，也没有把本地缓存伪装成远端成功结果的接口。
- 不提供按语言自动合并成单一案例正文的隐式聚合；一语言一案例，版本和语言通过 `translationGroupId` 组织。

## 4. 错误和重试

- 401：令牌缺失、过期或签名无效，需重新签发；不得在浏览器持有作者令牌。
- 403：Scope 不足或身份不匹配，需换发正确身份令牌。
- 404：资源不存在、已软删除或公开 release 不可见；不得用本地缓存替代。
- 409：版本冲突、项目 ID/编号重复、核心项目只读、素材被 release 引用或操作幂等冲突；先读取当前状态再决定收敛。
- 429：超过本地请求频率或并发限额；按 `Retry-After` 退避，不换新键绕过。
- 503 / 超时：远端或依赖不可用；本地 outbox 保持 `pending`，用同一 `operationId` 重试并查询操作结果。
- 对象上传失败时不得标记素材成功；上传票据过期后重新申请，不复用已过期票据。

## 5. 容量与安全

- 单次 PUT 32 MiB，分片 8 MiB，单素材总量 256 MiB。
- 单个服务身份默认每分钟 120 次请求；总并发 16、单身份并发 6。
- 对象桶私有、版本控制开启；网关不向调用方发放永久对象存储凭据。
- 作者、公开、媒体令牌均有时效；测试作者令牌不得进入仓库、日志、浏览器或发布包。
- MinIO 备用入口证书将在 2026-12-01 到期，需在到期前续签。
- LocalStack 4.8.1 的 IAM 拒绝断言不完整，仅离线测试用能力开关跳过；真实 MinIO 验收不能跳过。

## 6. 联调前置条件

1. 使用路径中给出的完整作者令牌，并在到期前完成本地 outbox 联调。
2. 项目创建只调用 `POST /projects`；更新、归档和恢复只调用 `PATCH /projects/{projectId}`。
3. 本地以远程返回的 `sourceVersion` / `rowVersion` 做并发控制；不得忽略 409。
4. 本地 outbox 保存稳定 `operationId`，失败保持 pending；远端查不到结果时按幂等结果接口重试。
5. 素材上传后等待处理状态进入可发布，再创建 release；不得把处理中素材当作可发布素材。
6. 存量迁移先冻结稳定 ID 和编号，按批次对账；不得直接复用测试验收 ID。
