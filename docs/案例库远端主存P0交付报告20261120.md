## 4. 项目目录与一致性

- `externalProjectId` 在所有核心历史摘要和本地项目中永久唯一；重复返回 `409 PROJECT_ID_EXISTS`。
- `projectCode` 在未软删除、未源缺失的可用目录项间跨来源唯一；重复返回 `409 PROJECT_CODE_EXISTS`。归档仍占用编号，软删除释放编号。
- 核心项目 PATCH 返回 `409 PROJECT_SOURCE_READ_ONLY`；本地项目按 `expectedVersion = sourceVersion` 乐观并发更新。
- 本地项目创建 `sourceVersion=1`；真实 PATCH 每次 +1；归档、解档、软删除、恢复均递增。无实际变化的 PATCH 成功但不递增。
- profile 有独立 `rowVersion`：首次保存 `expectedVersion=0` 返回 201；后续更新使用 profile 当前 `rowVersion`，同时提交项目目录当前 `sourceVersion`；过期返回 409。
- `project_directory` 是唯一合并读取路径；核心和本地来源均支持按 ID 立即读取，本地项目无需等待任何投影任务。
- 核心项目投影为常驻 `watch`，默认间隔 1000 ms；历史实测单轮水位约 0.2 秒，新增/修改通常在 1 秒左右可读。`CASE_PROJECTION_OVERLAP_SECONDS` 是回看窗口，不是刷新周期。

## 5. 案例、素材与发布

- 调用方可预生成 `caseId`；稳定 `operationId` 的重放返回首次结果。
- 一语言一案例；同一语言的独立编辑/审核/发布通过 `translationGroupId` 聚合。未提供按语言自动合并成单案例正文的接口。
- 每次真实案例变更追加 `case_versions`；版本提供不可变快照、版本号、变更摘要和恢复来源。无变化 PATCH 不新增版本。
- 素材以项目为作用域；同一 `assetId` 重新上传生成新的 `assetVersionId`，挂接表允许同项目多个案例复用。
- 素材元数据支持 `assetType`、标题、说明、locale、标签、密级、客户可见/讲解/分享标记；字段可空规则在字段字典中冻结。
- 上传单 PUT 32 MiB、分片 8 MiB、单素材 256 MiB；上传完成校验 SHA-256、MIME 和大小。新对象键为 `projects/{projectId}/assets/{assetId}/{assetVersionId}`。
- 预览/下载使用短时票据，不向调用方返回桶名、`object_key` 或永久凭据。
- AVIF 已支持 MIME 和文件头检测；测试机已实际上传、读取和预览。
- release 固定精确素材版本；被 release 引用的素材删除返回 `409 ASSET_REFERENCED`，归档允许。历史 release 不被后续编辑或版本更新改写。
